
CONFIGURACION DE SUPABASE

1. Abre el proyecto en Supabase y entra en SQL Editor.
2. Copia y ejecuta todo el contenido de supabase-setup.sql.
3. En Authentication > Users, crea el usuario y la contraseña que usaras para administrar la galeria.
4. Abre index.html desde un servidor web o publica la carpeta en Netlify.
5. Pulsa Administrar, inicia sesion y sube las fotos desde el celular.

La clave incluida en js/supabase-config.js es publica y esta pensada para el navegador.
No uses nunca una clave service_role en ese archivo.
