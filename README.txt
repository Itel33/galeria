GALERÍA FOTOGRÁFICA — INICIO

1. Abrí index.html en tu navegador.
2. El diseño usa HTML + CSS + JavaScript puro.
3. Los bloques grises son espacios reservados para tus fotografías.
4. La siguiente etapa puede ser reemplazar esos bloques por imágenes reales,
   agregar un visor a pantalla completa y conectar las 150 fotografías.

ESTRUCTURA:
- index.html
- css/style.css
- js/app.js
- fotos/  -> colocá aquí tus fotografías
